# Focus Guard

Windows 10/11向けの集中支援アプリ。タスクを選んで作業時間を記録し、各画面の右下に今やることを表示します。

## 起動・ビルド

```powershell
npm install
npm start
npm run package
```

ビルド後は `dist/FocusGuard-win32-x64/FocusGuard.exe` を起動します。配布時はフォルダー内のファイル一式が必要です。

## 使い方

1. ＋でタスク名・タグ・メモを登録します。タグはカンマ区切りで10個まで指定でき、既存タグも選択できます。
2. タスクを選び、▶で作業を開始します。使用アプリの指定は不要です。
3. 各モニター右下にタスク名と経過時間が表示されます。クリックするとアプリ画面が開きます。赤枠はありません。
4. メイン画面から一時停止・再開・終了、右下表示の非表示切替ができます。一時停止中の時間は作業時間に含めません。
5. 「履歴」で記録を確認し、右上のダウンロードアイコンでJSONLを保存できます。

タグの変更・解除は鉛筆アイコンから行います。一覧上部のタグで絞り込み、検索欄ではタスク名・メモ・タグを検索できます。アイコンの意味はマウスを重ねると表示します。

標準タイトルバーは非表示です。最上部の余白をドラッグすると移動でき、右上のボタンで最小化・最大化・終了できます。

タスクの完了は一覧のチェックで操作します。最小化中は計時を続け、ウィンドウを閉じると作業を終了して保存します。

## 作業の中断・切り替え

- 作業中に別のタスクを選んで切り替えアイコンを押すと、現在の作業を自動で中断し、選んだ作業を開始・再開します。
- 作業パネルの切り替えアイコンでは、現在の作業だけを中断できます。
- 「中断中」の▶で同じ作業の続きから再開し、■でその作業を終了できます。
- 中断時間は作業時間に含みません。中断中の作業はアプリを再起動しても保持します。

## 現行仕様

- 使用アプリの指定・制限・前面監視・脱線検知は撤去しました。PowerShellの監視プロセスは起動しません。
- 保存先は `%APPDATA%/focus-guard/data.json`。既存のタスク・履歴も引き継ぎます。
- 旧版の未処理の脱線検出は移行時にログへ保存し、入力画面は表示しません。過去のログは引き続き閲覧・出力できます。
- 内部データはJSON、出力はJSONL。日時はISO 8601のUTC、時間は整数秒です。
- 保存は一時ファイルへの書き込み後に置き換えます。異常終了後は最後の保存時刻までを記録し、一時停止状態で復元します。
- データの外部送信は行いません。

## 検証

```powershell
npm run check
npm test
npm run test:ui
```

画面テストは独立したテストデータでElectronを起動し、右下クリックによる画面復帰・セッション制御・保存・書き出しを確認します。
