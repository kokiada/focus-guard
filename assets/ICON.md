# Focus Guard icon

Generated with the built-in image_gen tool, 2026-09-08. Original image: `icon.png`. Windows multi-resolution icon: `icon.ico`.

Prompt:

> Use case: logo-brand. Generate one production-ready Windows desktop app icon for Focus Guard, a calm focus companion. Square 1024x1024 image, single icon, no mockup. A deep forest green rounded-square tile with a very subtle soft tonal gradient, bearing a bold ivory abstract focus ring with a small centered solid dot, the ring subtly suggesting a protective open circle. Extremely simple, distinctive geometric silhouette, thick clean shapes legible at 16px, balanced generous interior padding. Flat polished application icon, front facing, no text or letters, no red, no extra decoration, no watermark, no surrounding scene. The rounded tile should occupy almost the whole canvas with a small even transparent margin. Background outside the rounded tile must be genuinely transparent.

To rebuild the ICO while preserving transparency:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/build-icon.ps1
```
